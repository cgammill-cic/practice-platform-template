# Decision Log

One row per decision made while operating this app. Never delete a row; supersede it with a new dated
entry instead of editing history away.

Keeping a log like this is a habit worth continuing, not just a template placeholder: a future session
(yours, a colleague's, or an AI assistant's) can pick up months of context from this file in a few
minutes instead of re-deriving it from the code. Write down the decision, the reason it was made, what
was considered and rejected, and what it cost — not just what shipped.
